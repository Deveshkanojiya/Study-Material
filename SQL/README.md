# Backend Database Mastery

This repository contains structured notes for mastering SQL and database
concepts required for backend development.

The goal of this repository is to build **strong database intuition**
for real production systems and backend engineering interviews.

---

## Topics Covered

- SQL Fundamentals
- Joins
- Aggregations
- Window Functions
- Subqueries
- Common Table Expressions (CTE)
- Indexing
- Query Planner & EXPLAIN
- Query Optimization
- Pagination Strategies
- Transactions & Isolation Levels
- Join Execution Algorithms
- SQL Interview Problems

---

## Why This Repository Exists

Most developers learn SQL only at a surface level.

This repository focuses on:

- Understanding **how databases actually work**
- Learning **performance concepts like indexing and query planning**
- Preparing for **backend engineering interviews**
- Building **long-term revision notes**

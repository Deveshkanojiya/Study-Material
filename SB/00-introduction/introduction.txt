==================================================
SPRING FRAMEWORK VS SPRING BOOT
==================================================

# Why Spring?

Building enterprise Java applications from scratch is difficult.

Problems:

- Object creation
- Dependency management
- Database integration
- Security
- Transactions
- Boilerplate code

Spring Framework solves these problems.

--------------------------------------------------

# Spring Framework

Spring Framework is a Java framework that provides modules to build
enterprise applications.

Some major modules:

- Spring Core
- Spring MVC
- Spring Data
- Spring Security
- Spring AOP

Spring gives flexibility but requires configuration.

--------------------------------------------------

# Spring Boot

Spring Boot is built on top of Spring Framework.

Goal:

Reduce configuration and let developers focus on business logic.

Instead of configuring everything manually,
Spring Boot provides sensible defaults.

--------------------------------------------------

# Spring Framework vs Spring Boot

Spring Framework

- More configuration
- External server
- Manual dependency management
- Slower setup

Spring Boot

- Auto Configuration
- Embedded Tomcat
- Starter Dependencies
- Faster development

--------------------------------------------------

# Interview Points

Q. Is Spring Boot another framework?

No.

Spring Boot is built on top of Spring Framework.

-----------------------------------------------

Q. Does Spring Boot replace Spring?

No.

Spring Boot simplifies Spring.

--------------------------------------------------

# My Understanding

Spring Boot is simply a faster and smarter way of building Spring
applications.

It removes repetitive configuration so developers can focus on writing
business logic.

STARTER DEPENDENCIES
==================================================

# What are Starter Dependencies?

Starter Dependencies are pre-configured dependency bundles provided by
Spring Boot.

Instead of adding multiple libraries manually, we add one starter.

Spring Boot automatically pulls all required dependencies.

--------------------------------------------------

# Why do we need them?

Without Starters

Need to find every required library

Need compatible versions

Need to manage conflicts

Need manual updates

With Starters

One dependency

↓

Everything automatically downloaded

==================================================
AUTO CONFIGURATION
==================================================

# What is Auto Configuration?

Auto Configuration automatically configures Spring Boot based on the
dependencies present in the project.

No manual configuration is required in most cases.

--------------------------------------------------

# Example

Added

spring-boot-starter-web

↓

Spring Boot automatically configures

Dispatcher Servlet

Tomcat

Jackson

Spring MVC

Error Handling

Without writing configuration code.

--------------------------------------------------

# Internal Working

Application Starts

↓

Reads pom.xml

↓

Checks Dependencies

↓

Loads matching Configuration Classes

↓

Creates Required Beans

↓

Application Ready

--------------------------------------------------

# Why is Auto Configuration useful?

Less Boilerplate

Faster Development

Sensible Defaults

Production Ready Setup

--------------------------------------------------

# Can we override it?

Yes.

Spring Boot provides defaults.

Developers can override them whenever required.

# Common Mistake

Thinking Auto Configuration means "magic".

Wrong.

Spring Boot checks available dependencies and loads predefined
configuration classes.

Nothing happens randomly.

--------------------------------------------------

# My Understanding

Auto Configuration is the biggest reason Spring Boot became popular.

Instead of manually configuring every framework, Spring Boot detects
project requirements and configures most things automatically.

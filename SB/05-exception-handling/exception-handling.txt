EXCEPTION HANDLING
==================================================

# What is Exception Handling?

Exception Handling is the process of handling runtime errors gracefully
without crashing the application.

Instead of exposing stack traces,
APIs return meaningful error responses.

--------------------------------------------------

# Why Exception Handling?

Prevents Application Crash

Improves User Experience

Returns Proper HTTP Status Codes

Provides Consistent Error Responses

==================================================
@ControllerAdvice
==================================================

# Purpose

Provides Global Exception Handling.

Instead of handling exceptions in every controller,
Spring handles them from one central place.

--------------------------------------------------

Benefits

Cleaner Controllers

Reusable Exception Logic

Consistent API Responses

==================================================
@ExceptionHandler
==================================================

# Purpose

Handles a specific exception.

Example

ResourceNotFoundException

↓

404 NOT FOUND

--------------------------------------------------

One handler

↓

One Exception Type

==================================================
CUSTOM EXCEPTIONS
==================================================

# Why?

Java exceptions don't always describe business problems.

Example

User Not Found

Product Out Of Stock

Insufficient Balance

Order Already Cancelled

--------------------------------------------------

Creating custom exceptions makes APIs easier to understand.
